# Admin Tools

One-off and on-demand utility scripts — not part of the automated pipeline.

## Scripts
| Script | Purpose |
|--------|---------|
| `backfill_runner.py` | Process pending backfill requests from ingest_state |
| `backfill_symbol.py` | Full ingestion chain for one symbol |
| `n8n_api.sh` | n8n REST API helper (list, activate, import workflows) |
